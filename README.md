# Sales Data Analysis Project

## 📌 Project Overview
This project analyzes retail sales data to extract business insights and understand customer purchasing patterns.

---

## 🎯 Objectives
- Identify top-selling product categories
- Analyze sales across regions
- Study customer segments
- Evaluate the impact of discounts on profit

---

## 🛠 Tools & Technologies
- Python
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook

---

## 📊 Key Analysis Performed
- Data Cleaning
- Exploratory Data Analysis (EDA)
- Sales & Profit Analysis
- Customer Segment Analysis
- Discount vs Profit Analysis

---

## 📈 Key Insights
- Certain product categories generate higher revenue.
- Some regions outperform others in sales.
- High discounts negatively impact profitability.

---

## 📂 Dataset
Superstore Sales Dataset

---

## 🚀 How to Run the Project
1. Clone the repository
2. Install requirements
3. Open Jupyter Notebook
